# Atenea SSH has been retired

Atenea's proposed multi-host SSH product is retired. The draft implementations in [PR #157](https://github.com/Tutitoos/atenea/pull/157) and [PR #158](https://github.com/Tutitoos/atenea/pull/158) were not merged into `main`. The retirement and recovery record is tracked in [issue #195](https://github.com/Tutitoos/atenea/issues/195); the original roadmap and architecture remain available as [issue #141](https://github.com/Tutitoos/atenea/issues/141) and [issue #142](https://github.com/Tutitoos/atenea/issues/142).

For local graphical interaction on a Mac, see [Computer Use]({{< relref "computer-use" >}}). Its current `desktop.*` MCP surface, application policy, permissions, and evidence limits are documented there. Local operation is tracked separately in [issue #196](https://github.com/Tutitoos/atenea/issues/196).

This retirement applies only to the proposed Atenea product. It does not change macOS OpenSSH, `~/.ssh`, SSH agents or keys, or access used by other tools and projects.
